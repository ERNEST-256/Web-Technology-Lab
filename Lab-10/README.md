# Lab 10 - React JS Advanced

This folder contains three separate React websites, one for each exercise in the lab sheet.

## Websites

- `Ex-1/` - Form validation using controlled components and `useState`
- `Ex-2/` - Dynamic list rendering with add and remove operations
- `Ex-3/` - API data fetching using `useEffect` with loading and error states

The root `index.html` works as a landing page with links to all three exercises.

## Run the project

1. Open a terminal in `Lab-10`
2. Install dependencies with `npm install`
3. Start the development server with `npm run dev`
4. Open:
   - `/Ex-1/`
   - `/Ex-2/`
   - `/Ex-3/`
