# Lab 9 - React JS Basics

This folder now contains three separate React websites, one for each exercise in the lab sheet.

## Websites

- `Ex-1/` - Student profile using JSX and a functional component
- `Ex-2/` - Reusable student cards using props
- `Ex-3/` - Interactive counter using the `useState` hook

The root `index.html` acts as a landing page with links to all three exercises.

## Run the project

1. Open a terminal in `Lab-9`
2. Install dependencies with `npm install`
3. Start the development server with `npm run dev`
4. Open:
   - `/Ex-1/`
   - `/Ex-2/`
   - `/Ex-3/`
