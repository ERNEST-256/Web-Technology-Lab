# Lab 11 - Node JS Basics

## Exercise 1
A basic HTTP server using Node.js `http` module.

Run:
```bash
node Ex-1.js
```
Then open `http://localhost:3000` in a browser.

## Exercise 2
File operations using Node.js `fs` module: create, read, append, read, delete.

Run:
```bash
node Ex-2.js
```

## Exercise 3
Event-driven programming using `EventEmitter` with custom events and multiple listeners.

Run:
```bash
node Ex-3.js
```
